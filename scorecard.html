Scorecard

Computed from your journal (closed trades only: those with an exit date and P&L). Per track, so the 0DTE lab never hides inside the main track's numbers.

How these are calculated

  • Win rate = trades with P&L > 0 ÷ closed trades. Breakeven trades (P&L = 0) count as non-wins.
  • Average win / loss = mean P&L of winners / of losers.
  • Expectancy = win rate × average win − loss rate × average loss = average P&L per trade.
  • Breakeven win rate = average loss ÷ (average win + average loss), using your own averages (Module 07).
  • Average days held = exit date − entry date.
  • Fewer than 20 closed trades: treat every number as noise (Module 06).
